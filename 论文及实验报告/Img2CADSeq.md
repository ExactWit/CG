# Img2CADSeq: Image-to-CAD Generation via Sequence-Based Diffusion 
> 论文出处：SIGGRAPH 2026
> 作者团队：清华大学软件学院
> 核心任务：从单视图图像生成符合工业标准的BRep格式CAD模型（可直接输出STEP文件），提出基于序列扩散的多阶段生成管线

## 1. 研究问题（Problem）
1. **现有3D生成的工业适配性缺陷**
    基于NeRF、3D高斯溅射、网格扩散的单视图3D生成方法，仅能输出隐式场、非结构化点云或普通网格，缺乏CAD所需的参数化几何与显式拓扑结构，无法直接用于精密设计、工业制造等下游工程任务。

2. **BRep重建的固有难点**
    边界表示（BRep）是工业CAD的标准格式，依赖复杂的几何实体拓扑关系。现有将BRep建模为操作序列的方案，普遍存在序列过长、结构无序的问题，深度模型难以有效学习拓扑约束；同时2D像素与3D参数化CAD序列之间存在巨大模态鸿沟，直接映射会丢失深度与拓扑信息，易产生结构幻觉。

3. **现有图像转CAD方案的瓶颈**
    - 基于法线图、SVG等2D中间表示的方法，本质上丢失3D拓扑信息，重建问题高度不适定；
    - 训练数据多为通用物体数据集（如ShapeNet），缺乏工业零件的几何严谨性，域适配能力差；
    - 点云转CAD的传统拟合方法输出不可编辑，大语言模型类方法资源消耗高且对噪声敏感。

## 2. 核心动机（Motivation）
1. **工业逆向工程的实际需求**：自动化从单张实物照片/设计图生成可编辑、符合工程标准的CAD文件，替代人工重建的高成本流程。
2. **设计逻辑的启发**：工业设计遵循“先整体轮廓，后局部细节”的优先级原则，可将CAD操作序列进行层级化拆解，降低模型学习难度，同时隐式保证拓扑合理性。
3. **中间模态的桥梁作用**：用3D点云作为2D图像到CAD序列的中间表示，相比2D中间表征保留更多空间结构信息，缓解单视图深度歧义。
4. **数据驱动的域适配**：通过合成工业数据集+真实拍摄零件数据联合训练，缩小仿真到真实场景的差距，提升模型在工业场景的鲁棒性。

## 3. 方法方案（Solution）
整体为三阶段流水线：**层级化CAD序列编码 → 几何感知点云提取与精炼 → 跨模态对齐+条件扩散生成**。

### 3.1 层级化CAD序列编码
提出三层级离散码本（Curve-Cluster / Sketch-Patch / Extrude-Block），对应“局部几何→拓扑布局→全局语义”的设计逻辑，通过三个独立VQ-VAE将长操作序列压缩为稳定的离散潜空间。

#### 3.1.1 三层编码结构
1. **Extrude-Block (EB) 层：全局语义抽象**
    将单个拉伸块的核心建模参数通过MLP编码为全局特征向量，捕捉整体结构语义：
    $$e^{eb}=MLP_{global }\left(n_{sketch } \oplus p_{origin } \oplus h_{ext } \oplus b_{type }\right)$$
    其中$\oplus$为特征拼接，$n_{sketch}, p_{origin} \in \mathbb{R}^3$为草图平面的单位法向量与原点，$h_{ext}$为拉伸深度，$b_{type} \in \{0,1\}^3$为布尔操作（新建、求和、求差）的one-hot编码。

2. **Sketch-Patch (SP) 层：拓扑布局与空间锚定**
    对草图中的闭环轮廓进行优先级排序，评分规则为**面积与对角线尺度优先，坐标位置作为平局判定**：
    $$S_{m} = (w_m \times h_m) + \alpha \cdot \sqrt{w_m^2+h_m^2} - \beta \cdot (x_m+y_m),\quad \alpha \gg \beta$$
    保证主导轮廓排在序列前端，匹配“先整体后局部”的设计逻辑。
    每个闭环的起始坐标、起始切角等通过MLP编码，同时作为下层CC层的空间锚点，实现平移不变的局部几何编码：
    $$e_{m}^{sp}=MLP_{layout }\left(S_{m} \oplus p_{start }^{(m)} \oplus \theta_{start }^{(m)}\right)$$

3. **Curve-Cluster (CC) 层：局部几何参数化**
    抛弃绝对坐标，采用局部Frenet坐标系描述每个几何基元（直线、圆弧），每个基元编码为8维特征：
    $$f_{i}=\left[ l_{i},\Delta \theta _{i},\kappa _{i},\delta x_{i},\delta y_{i}\right] \oplus t_{i}$$
    其中$l_i$为弦长，$\Delta \theta_i$为相对切向偏差，$\kappa_i$为曲率，$(\delta x_i, \delta y_i)$为残差偏移（用于保证轮廓闭合），$t_i$为基元类型的one-hot向量（直线、圆弧、结束符）。
    特征经MLP映射为潜码$e_i^{cc}$，序列仅以`<EOS>`结束，去除冗余分隔符，提升序列可学习性。

#### 3.1.2 训练目标
三个层级各对应独立的VQ-VAE模型，总损失为三项加权和：
$$\mathcal{L}=\mathcal{L}_{recon }+\mathcal{L}_{vq}+\lambda_{cls } \mathcal{L}_{closure }$$
- $\mathcal{L}_{recon}$：混合重建损失，连续几何参数用MSE、离散类别标签用交叉熵；
- $\mathcal{L}_{vq}$：向量量化损失，采用标准commitment机制稳定码本更新；
- $\mathcal{L}_{closure}$：闭环正则损失，惩罚CC层路径重建的累积欧氏误差，保证生成模型的水密性。

### 3.2 几何感知点云提取与精炼
作为2D图像到CAD序列的中间桥梁，分两步得到带结构先验的高质量点云特征。

#### 3.2.1 单视图点云生成
基于Dens3R基础模型，采用**参数高效微调（PEFT）** 策略，仅微调Query和Value线性层，在工业数据集上适配刚性几何先验，将单张图像提升为初始粗点云$P_{raw}$。

#### 3.2.2 UA-DGCNN与启发式重采样
提出**不确定性感知DGCNN（UA-DGCNN）**，预测每个点的几何重要性分数$s_i \in [0,1]$（高曲率、尖锐边缘区域分数更高），并设计混合概率的启发式重采样策略：
$$p\left(p_{i}\right)=\underbrace{\lambda \cdot \frac{e^{\beta s_{i}}}{\sum_{k} e^{\beta s_{k}}}}_{\text{显著性项}}+\underbrace{(1-\lambda) \cdot \frac{1}{N}}_{\text{覆盖项}}$$
- 显著性项：基于玻尔兹曼分布，优先保留尖锐边缘、角点等关键几何特征；
- 覆盖项：均匀采样保证平面区域的点分布，避免出现空洞；
- $\lambda$为两项的平衡系数。

采样得到精炼点云$P_{ref}$，再通过几何编码器得到结构嵌入$z_P$，用于后续跨模态对齐。

### 3.3 跨模态对齐与条件扩散生成
#### 3.3.1 对比学习跨模态对齐
通过对比学习将点云嵌入空间与CAD序列嵌入空间对齐，构建共享语义流形。采用因果Transformer编码CAD序列得到全局嵌入$z_S$，以配对的点云-序列为正样本，批次内其余样本为负样本，优化对称InfoNCE损失：
$$\mathcal{L}_{NCE}=-\frac{1}{B} \sum_{i=1}^{B} log \frac{exp \left(sim\left(z_{\mathcal{S}, i}, z_{\mathcal{P}, i}\right) / \tau\right)}{\sum_{k=1}^{2 B} I_{[k \neq i]} exp \left(sim\left(z_{S, i}, z_{feat , k}\right) / \tau\right)}$$
其中$sim(u,v)$为余弦相似度，$\tau$为可学习温度参数，$z_{feat}$为批次内所有点云与CAD嵌入的集合。

#### 3.3.2 条件VQ-Diffusion生成
采用**吸收态离散扩散模型（VQ-Diffusion）**，以对齐后的点云特征$c=z_P$为条件生成CAD序列token：
- 前向过程：逐步将序列token替换为`[MASK]`，逐步腐蚀序列信息；
- 反向过程：Transformer解码器通过交叉注意力注入条件特征，从带噪序列中恢复干净的CAD离散token。

训练目标为变分下界与辅助交叉熵的结合：
$$\mathcal{L}_{gen }=\mathcal{L}_{vlb }+\lambda_{aux } \mathbb{E}_{t, x_{t}}\left[-log p_{\theta}\left(x_{0} | x_{t}, c\right)\right]$$
最终通过几何内核将生成的token序列编译为标准STEP格式的水密BRep模型。

## 4. 配套数据集
为解决工业数据稀缺与sim2real迁移问题，构建两个专用数据集：
1. **CAD-220K**：从ABC数据集筛选的22万个工业CAD模型，按面数分层采样，配套四视图渲染图、点云、STL文件，覆盖不同复杂度的机械零件；
2. **PrintCAD**：2000余个3D打印实物的真实拍摄图像，覆盖尼龙、树脂、PLA等材料，包含真实光照与制造噪声，用于验证模型的真实场景泛化能力。

## 5. 核心贡献（Contributions）
1. **层级化序列编码框架**：提出三层码本结构，遵循“轮廓到细节”的设计逻辑，将长CAD操作序列压缩为稳定的离散潜空间，在保证拓扑有效性的同时显著提升了序列的可学习性。
2. **工业适配的中间表示方案**：以点云为跨模态桥梁，提出UA-DGCNN与启发式重采样策略，结合“合成+真实”双数据集的微调方案，有效缩小sim2real差距，提升工业零件的重建精度。
3. **跨模态对齐的生成管线**：通过对比学习对齐点云几何特征与CAD序列潜空间，引导VQ-Diffusion生成拓扑有效的CAD序列，最终输出可直接用于商用CAD软件的标准STEP文件。
4. 实验验证：在**图像条件生成、点云条件生成、无条件生成**三个任务上全面超越现有SOTA模型，在几何精度、拓扑完整性、结构多样性上均有显著提升；消融实验验证了每个核心模块的有效性。

## 6. 局限性与未来方向（Limitations & Future Work）
### 6.1 局限性
1. **单视图固有歧义**：遮挡区域会基于训练先验生成结构，视觉上合理但可能不符合物理制造与运动学约束，极端遮挡下会出现无法加工的结构。
2. **长序列误差累积**：层级编码对局部特征建模较好，但缺乏显式全局约束，长序列生成中误差累积会破坏严格对称、同轴度等全局几何约束。
3. **精细特征丢失**：中间点云分辨率有限（4096点），启发式重采样会平滑掉螺纹、微小圆角等微观制造特征，导致精密细节丢失。
4. 真实场景泛化有限：PrintCAD以3D打印零件为主，对更复杂的工业场景、材质、工艺的泛化能力仍有不足。

### 6.2 未来工作
- 引入视觉语言模型（VLM）实现多模态条件输入，缓解单视图歧义；
- 支持中间阶段的交互式编辑，提升工程实用性；
- 在扩散模型中显式引入对称、同轴等全局几何约束；
- 拓展数据集覆盖更多工业场景与制造工艺。
